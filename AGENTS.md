# AGENTS.md

- Project ini adalah EMS MVP untuk pembelajaran fullstack.
- Pertahankan arsitektur MVC + Service + Repository.
- Jangan return Entity langsung dari Controller.
- Gunakan DTO untuk request dan response.
- Endpoint `/api/auth/login` dan `/api/health` harus public.
- Endpoint `/api/admin/**` harus ADMIN only.
- Frontend harus tetap Vanilla HTML/CSS/JS.
- Docker Compose harus tetap bisa menjalankan mysql, backend, dan frontend.
- Jangan tambah fitur besar tanpa instruksi khusus.
- Prioritaskan perubahan kecil, aman, dan mudah dites.
